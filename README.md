# Scrap
Scrapping Content from Websites

## Install
```
git clone git@github.com:veto8/scrap.git
cd scrap
python3.12 -m venv env
. env/bin/activate
pip install pip --upgrade
pip install -r requirements.txt
```

## Run
```
python main.py
```

## Dependencies
- BeautifulSoup4
- Selenium
